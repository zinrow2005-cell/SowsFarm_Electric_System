# Apps Script 雙模式部署說明

1. **先備份**原始 Google Sheet、Drive 專案 JSON 與 Apps Script，並保留可復原版本。
2. 將 `Code.gs` 貼入既有 Google Sheet 綁定的 Apps Script 專案。先在指令碼屬性加入 `ADMIN_USER=dad`、`ADMIN_PASSWORD=自選至少12字元的新密碼`。**不要使用 1234；也不要將密碼貼到 GitHub。**
3. 執行 `setupCloud()`（如果已存在原資料，它只會確保必要資源存在）；再執行 `initializeAdmin()`，該函式會將密碼雜湊加鹽後儲存，並刪除明文密碼與舊 Token。
4. 重新部署 Web App，執行身分選「我」，可存取對象依員工匿名開啟需要設為「任何人」。**務必停用曾使用共用 Token 的舊版部署**，否則任何持有舊 Token 者可能仍可寫入。
5. GitHub 上傳本包網頁，開啟選「管理者端」登入。第一次請在右上雲端設定確認 Apps Script `/exec` 網址，並手動上傳目前專案，這份雲端版本才會成為員工公開讀取的配置。
6. 員工端免登入讀取 `publicProject`。專案中所有設備說明會對持有網址者公開，請勿保存個人資料、私密密碼或機密照片連結。
7. 管理者登入授權有效約六小時，在記憶體保存，不會把密碼或永久寫入 Token 存在公開網站。

**注意**：這是最小可用的密碼登入方案。Google Apps Script 沒有原生強健的帳密登入與速率限制，正式多人部署更推薦 Google 身分登入、Cloud Run / Firebase Authentication 與 Firestore 規則。此版密碼服務不具備防暴力破解能力，切勿使用四位數密碼。照片檔仍受 Drive 分享設定限制，匿名員工可能看不到照片；要公開照片需另外設計安全的唯讀媒體代理與存取規則。GitHub PWA、應用資料與雲端版本分開更新。員工每分鐘檢查一次雲端版本。更新通知／自動顯示依連線狀況而定。
