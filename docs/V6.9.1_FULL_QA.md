## 找到並修正的實際問題

### 桌機中等寬度工具列重疊

在約 1280–1440px 的桌機視窗，中央 CAD 可用寬度受到左右側欄影響，
「收合右欄」按鈕會伸到右上角 `－ / ＋` 縮放鍵下方。

實際測試時：
- 1440px：右欄按鈕中心會點到 `－`
- 1366px / 1280px：部分區域會點到 `＋`

V6.9.1 已修正：
- 1101–1500px 讓 CAD 工具列自動換行
- 保留右側縮放鍵安全區
- 工具間距在中等桌機略微縮小
- 設備快選面板同步下移，避免和第二排工具重疊

修正後重新測試 1920、1600、1440、1366、1280、1200、1110、1101、1100、1024、768、390px，
右欄按鈕中心均可正確點到自己，沒有再被 `－ / ＋` 蓋住，也沒有水平頁面溢出。

## 尚不能等同實機驗證的項目

- Google Apps Script / Google Sheet / Drive 真實雲端寫入：需要你的實際 `/exec` URL 與 Token。
- 手機相機：檔案選擇與照片處理流程已測，但 headless Chromium 沒有實體鏡頭。
- iOS Safari：本次為 Chromium 觸控尺寸與 PointerEvent 測試，不等同真正 iPad Safari 實機測試。

因此本版可以作為下一個 GitHub 測試版本，但上 GitHub 後仍建議用你自己的 iPad Safari 做一次雲端 + 相機最後驗收。
