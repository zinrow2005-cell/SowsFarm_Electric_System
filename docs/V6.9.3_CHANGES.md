## 2. 左側欄字體放大

左側操作欄原本有 9px、10px、11px、12px 混用，現場看起來不一致。

本版統一：
- 區塊標題：約 15px
- 按鈕 / 下拉選單 / 輸入欄：約 13px
- 說明 / 標籤 / 設備庫：約 12.5px
- 設備篩選 chip：約 12px

手機 / iPad 也維持同一閱讀邏輯，不再把左側按鈕縮得太小。
