# 虎尾場 2D CAD V6.9.7 全場重繪校正版

本版以 V6.9.6 為基礎，將上半部母豬場 CAD 底圖做成「整版校正」思路，而不再只是局部補線。

## 這次實際修正

1. **公豬舍右上角**
   - 依使用者最新指示，改成與上方產房 B 棟相接的斜角邊牆。
   - 公豬舍點選區改為多邊形，不再使用過度簡化矩形。

2. **採精室與儲物室之間走道**
   - 在底圖重新劃出採精室、儲物室與中間走道，不再視覺連成一塊。
   - 新增獨立 hotspot：`採精室與儲物室間走道`。

3. **浴室 2 下方**
   - 移除原本不該存在的 1.6 牆線感。
   - 保留浴室 2 本體，並重整左上區域牆線。

4. **上半部區域重整**
   - 同步重畫公豬舍上緣、麻布袋洗曬區上緣、廁所/洗衣曬衣區與左側房間群的可視牆線。

## 保留項目

- 全場其餘棟舍配置與面積標示維持原版本。
- 原有 GitHub Web CAD 系統互動功能保留。

## 注意

- 此版本仍屬 **Web CAD 平面底圖校正版**，並非原生 DWG 檔。
- 幾何位置是依照目前提供的截圖與既有圖面整合修正，適合繼續校稿；若要施工級 CAD，仍建議後續再做完整向量化。
