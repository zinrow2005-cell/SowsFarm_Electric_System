# V6.9.2 棟舍定位修正版

本版針對棟舍快速定位做小幅修正，不增加新的操作頁面。

## 修正 1：產房 C 定位

原本產房 C 使用矩形區域：
- x=688
- y=65
- w=507
- h=290

因為產房 C 本身是斜四邊形，矩形範圍會吃到上方尺寸線與中央走道，
右下方也無法準確貼合 C / D 分界。

V6.9.2 改成依 CAD 圖實際斜邊設定四點區域：

- 左上：約 (739,137)
- 右上：約 (1197,242)
- 右下：約 (1157,446)
- 左下：約 (700,338)

定位縮放會用這四點的外接範圍計算，
定位提示則直接畫出斜四邊形，不再用不準確的矩形框。

## 修正 2：移除「浴室2」

棟舍快速定位下拉選單已移除「浴室2」。
程式中的浴室2快速定位資料也一併移除。

## 修正 3：棟舍選單字體放大

桌機：
- 字體 13px
- 最小高度 38px

iPad / 較窄畫面：
- 字體 12px
- 最小高度 40px

手機：
- 字體維持 12px
- 控制選單寬度避免把工具列擠爆

## 備註

產房 C 的定位區域是依目前 V6.9.1 CAD raster 圖面像素座標校正。
如果之後更換 CAD 底圖版本，棟舍定位座標需要跟著重新校正。
